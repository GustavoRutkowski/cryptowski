# Cryptowski - V1

Esse documento explica passo-a-passo de como a V1 do algoritmo de criptografia funciona.

Tenha em mente que os algoritmos de criptografia foram desenvolvidos para fins acadêmicos e não devem ser utilizados como um mecanismo de criptografia real.

## O Algoritmo

O algoritmo segue a interface principal do sistema e implementa os métodos `Encode` e `Decode` da sua própria maneira.

### Keygen (Transformação de Chave)

A primeira etapa tanto do Encode quanto do Decode é realizar uma transformação de chave que garante que um texto seja transformado em um conjunto de caracteres

O algoritmo de derivação de chave funciona da seguinte maneira:

1. O sistema percorre cada caractere da chave;
2. Cada caractere é convertido um byte `B` (inteiro de 0 a 255);
3. Com base nisso, o programa utiliza um algoritmo de ***Miller-Rabin*** para encontrar um número primo `P` com `B` algarismos;
4. Cada caractere `Bi` é codificado usando `Bi * Pi`;
5. O resultado é armazenado em uma lista que representa a chave gerada;

Além disso, o sistema também soma os valores numéricos de todos os caracteres para gerar um valor auxiliar usado no processo de criptografia.

### Encode

O algoritmo de codificação funciona da seguinte maneira:

1. O sistema utiliza o algoritmo `Keygen` para derivar a chave utilizada;
2. Percorre cada byte do conteúdo que será criptografado.
3. Para cada posição:
    1. seleciona um valor da chave gerada;
    2. quando a chave acaba, reinicia do começo (índice circular);
    3. pega o valor do byte original;
    4. soma os valores usando a fórmula:
    ```
    (T[i] + S + K[j]) % 256
    ```
    Onde:
    `T[i]` -> Byte original do texto
    `S` -> Soma dos caracteres da chave
    `K[j]` -> Valor correspondente da chave gerada
    `256` -> Constante representando o tamanho máximo de um byte. Ela aplica um módulo que limita o tamanho do inteiro gerado entre 0 e 255
    5. O valor final dessa operação se torna o byte criptografado.

5. Devolve o conjunto de bytes criptografados

### Decode

O algoritmo de decodificação funciona da seguinte maneira:

1. O sistema utiliza o algoritmo `Keygen` para derivar a chave utilizada;
2. Percorre cada byte criptografado.
3.  Para cada posição:
    1. seleciona o valor correspondente da chave gerada;
    2. reutiliza a chave em ciclo contínuo;
    3. pega o byte criptografado;
    4. realiza a operação inversa da criptografia usando:
    ```
    (T[i] - S - K[j]) % 256
    ```
    4. Isso faz o valor voltar para a faixa válida de bytes (0–255), recuperando o dado original.

## CLI

Para indicar ao CLI que quer utilizar esta versão do algoritmo, basta rodar os comandos `crptowski encode`, `cryptowski decode` ou `bruteforce` com a flag `--v1`.
